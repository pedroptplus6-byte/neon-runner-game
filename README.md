# Neon Runner

A browser-based 3D endless runner with planet-themed worlds, rail routes, trains, hoverboards, missions, and customizable runners.

## Play

Open the [Neon Runner game](https://pedroptplus6-byte.github.io/neon-runner-game/) in a modern browser. An internet connection is needed to load the Three.js engine.

## Controls

- Left / Right arrows: change lanes
- Up arrow or Space: jump
- Down arrow: slide
- B: ride hoverboard
- Escape: pause
